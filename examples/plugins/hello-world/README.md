# Hello world plugin

A minimal Rakazo plugin: a manifest and one skill. Copy this folder to start your own, then read
[Build a plugin](https://rakazo.com/docs/build-a-plugin/).

To try it, open **Integrations** in Rakazo, choose **+** → **From GitHub**, and paste
`https://github.com/elie222/rakazo/tree/main/examples/plugins/hello-world`.
